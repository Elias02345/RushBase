# Rushbase

Self-hosted, AI-assisted media library for video, photo and audio rushes on network storage.

> Status: under active development (milestone M0). See `docs/STATUS.md`.

Rushbase watches an `Input/` folder on your NAS, lets workers analyse new material
(technical metadata, shots, transcripts, visual content, categories), files it into a
stable `Content/` structure with sidecar metadata and makes everything searchable —
for humans (web UI, companion app with GUI and CLI) and for AI agents (MCP).
